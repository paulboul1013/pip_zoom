# PiP Zoom

[English version](README.md)
 
PiP Zoom 是一個瀏覽器擴充套件，可以將網頁影片中由使用者選取的區域顯示成子母畫面（Picture-in-Picture）。

## 使用方式

1. 開啟一個正在播放影片的網頁。
2. 點擊瀏覽器工具列上的 PiP Zoom 圖示。
3. 在影片上拖曳選取想觀看的範圍。
4. 按下「啟動 PiP」。
5. PiP 播放中，再次點擊瀏覽器工具列上的 PiP Zoom 圖示即可旋轉 90 度；持續點擊會循環四個方向。
6. 關閉 PiP 後返回原影片。

## 載入方式（開發版）

1. 開啟瀏覽器的擴充套件管理頁面：

   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   - Brave：`brave://extensions`

2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」。
4. 選擇本專案的 `dist/` 資料夾。

## 支援瀏覽器

- Google Chrome
- Microsoft Edge
- Brave
