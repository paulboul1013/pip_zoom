# PiP Zoom

PiP Zoom 是一個瀏覽器擴充套件，可以將網頁影片中由使用者選取的區域，顯示成子母畫面（Picture-in-Picture）。

例如：只放大影片直播、教學影片的一角，而不是觀看整部影片。

## 使用方式

1. 開啟一個正在播放影片的網頁。
2. 點擊瀏覽器工具列上的 PiP Zoom 圖示。
3. 在影片上拖曳選取想觀看的範圍。
4. 按下 影片左上角的「啟動 PiP」按鈕。
5. 關閉 PiP 後，原本的網頁影片會恢復正常顯示。

## 載入方式

1. 開啟瀏覽器的擴充套件管理頁面：

   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   - Brave：`brave://extensions`

2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」。
4. 選擇本專案的 `dist/` 資料夾。
